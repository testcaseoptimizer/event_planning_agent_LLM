Implemented Retrieval Augmented Generation(RAG) to create an agent that is trained on a particular dataset,
and the memory is imbibed so that it gives the user information on guests coming to the gala party.


Optimized and tuned the agent by utilizing the Hugging Face model (Inference Client model) and integrated many tools
like DuckDuckGoSearchTool, HubStatsTool, so that ample utilities are provided to tackle many scenarios effectively.
